Finalidad

Los datos se procesan exclusivamente para gestionar la verificación del servidor, reducir el abuso de múltiples cuentas y permitir la revisión de coincidencias por parte del equipo autorizado de moderación.

Datos tratados

La solicitud puede incluir tu identificador de Discord, fecha de verificación, dirección IP transformada mediante HMAC, ubicación aproximada, zona horaria, idioma, navegador, sistema operativo, tipo general de dispositivo y señales de VPN, proxy o red de alojamiento cuando estén disponibles.

Datos que no recopilamos

No solicitamos ni accedemos a contraseñas, mensajes privados, cookies, archivos, fotografías, contactos, cuentas personales ni contenido almacenado en tu equipo.

Evaluación de coincidencias

Las señales se comparan con verificaciones anteriores para obtener una puntuación orientativa. Una dirección IP coincidente no se considera prueba suficiente por sí sola. Los casos de riesgo pueden enviarse a revisión humana y no implican una sanción automática.

Conservación y seguridad

Las señales técnicas se conservarán inicialmente durante un máximo de 90 días, salvo que sea necesario atender una revisión activa. Se aplican tokens temporales, controles de acceso y consultas parametrizadas. La dirección IP no se almacena en texto plano.

Decisión del usuario

La verificación solo comienza después de aceptar expresamente este aviso. Si no estás de acuerdo, puedes cerrar la página y no se enviarán señales técnicas al sistema de verificación.
